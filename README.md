# 沪深京实时行情筛选器

> 基于 `akshare` + `tushare` 的实时条件筛选器，支持 **季度慢池 + 盘中快筛 + diff 自动进出**。

## 功能特性

### 🎯 筛选字段（41个）
| 分组 | 字段 |
|---|---|
| **基础** | 代码、名称、二级行业、周期性 |
| **行情** | 现价、涨幅、3分钟涨速 |
| **资金** | 主力流速、超大单/大单/中单/小单净额 |
| **DDX** | 当日/5日/10日/20日 DDX、主力增仓% |
| **盘口** | 内外比、量比、换手率、成交金额 |
| **阶段** | 5/10/20/60日涨幅 |
| **估值** | 总/流通市值、PB、PE(静/TTM/动) |
| **财务** | 净利润同比、ROE、毛利率、资产负债率、股息率 |

### 🔄 核心架构
```
季度慢池 (财报级, 天级刷新)  ──▶  盘中快筛 (行情级, 15~30s/轮)  ──▶  diff 自动进出
  沪深主板 ∩ 市值 ∩ ROE               股价 ∩ DDX ∩ 量比 ∩ 换手             ✅进入  ❌出局
  ∩ 现金流 ∩ 周期股过滤              ∩ PE/PB 均值比 ∩ PEG
```

### 📊 周期股过滤（重点）
- **申万行业分级**：`strong` / `mid_strong` / `mid` / `mid_weak` / `weak` / `none`
- **强度滑块**：一键排除强周期 / 中强周期
- **申万二级精细排除**：如排除"煤炭开采"但保留"贵金属"
- **周期性评分模型**（V2）：基于毛利率波动率、净利润波动率量化打分

## 安装与运行

```bash
pip install streamlit pandas akshare tushare
streamlit run app.py
```

## 使用说明

### 1. 侧边栏控件
- **行情**：股价上限、内外比、量比、换手率、成交金额
- **DDX**：当日/5/10/20日阈值
- **市值/估值**：流通市值、PB、各类PE、PE动/静、PE动/TTM
- **财务**：ROE、资产负债率、股息率、PEG
- **周期股过滤**：强度滑块 + 二级行业多选排除

### 2. 默认参数（宽松）
> 为保证首次使用有结果，默认参数较宽松。**用户可逐步收紧**。

### 3. 空结果诊断
当筛选结果为空时，系统自动分析**是哪个条件太严**，提示用户放宽。

### 4. 列设置
- **拖动排序**：通过 multiselect 调整字段顺序
- **手动调宽**：每列宽度可通过 slider 微调
- **字号**：15px（约9pt），一屏显示更多字段

## 接实盘数据

当前为 MOCK 模拟数据。接实盘只需替换 `app.py` 中的数据源：

```python
# 财报慢池 (tushare)
from tushare import Tushare
ts = Tushare(token="YOUR_TOKEN")
df = ts.daily_basic(ts_code="000001.SZ", fields="pe_ttm,total_mv,circ_mv,...")

# 实时行情 (akshare)
import akshare as ak
spot = ak.stock_zh_a_spot_em()  # 全市场快照
```

## 文件结构
```

cycle_filter.py   # 周期股过滤模块 (申万分级 + 评分)
test_app.py       # 单元测试
final_test.py     # 需求点验证
verify_app.py     # 模块结构检查

```

## 注意事项
1. **DDX / 内外比**：akshare 快照未必包含，需另接东财资金流接口
2. **市现率 / 经营现金流**：需 tushare `fina_indicator` 接口
3. **防反爬**：财报接口勿高频并发，建议开盘前一次性拉取缓存
4. **实时性**：akshare 为准实时（10~30s），非毫秒级推送
